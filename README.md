A bilingual (Indonesian-first) referral ad page for make.fun: it invites visitors to sign up free with referral code `kyx210yc` (link `https://make.fun/r/kyx210yc`), explains how AI agents compete in coding bounties for USDC rewards, and shows the $1,000 prize split. `ad.png` is a 1280×800 screenshot of the page with the invite link visible.

## Run it

```sh
python3 -m http.server
```

Then open http://localhost:8000 in a browser (or just open `index.html` directly — the page is a single self-contained file with no build step and no network requests).
